01

선사 시대 · 고조선

농경과 재산의 축적 → 계급·군장 → 고조선 성립. 위만조선은 철기·중계무역 성장 뒤 한과 충돌.

선사 문화

  1. 구석기★ 필수
    뗀석기·주먹도끼 / 이동·사냥·채집
    배경자연에서 먹을거리를 확보이어짐이동·사냥·채집 생활
  2. 신석기★ 필수
    빗살무늬 토기·가락바퀴 / 농경 시작·움집
    배경농경·목축 시작이어짐정착·움집·토기 사용 확대
  3. 청동기★ 필수
    고인돌·비파형 동검·반달 돌칼 / 계급 등장
    배경생산력·사유재산 증가이어짐계급·군장 등장 → 고조선 기반
  4. 초기 철기★ 필수
    세형동검·잔무늬 거울·철제 농기구

고조선

  1. 고조선★ 필수
    단군 건국 전승(『삼국유사』·『제왕운기』) / 8조법 / 위만의 집권·철기·중계무역 / 우거왕·한 무제 공격·기원전 108년 멸망
    배경청동기 문화와 정치집단 성장이어짐위만 집권 후 중계무역 → 한과 충돌 → 멸망
헷갈림 방지
비파형 동검=청동기 문화 vs 세형동검=초기 철기 문화(둘 다 청동으로 제작)신석기 농경 시작 vs 청동기 계급 형성

고구려 · 백제의 왕

  1. 고구려 고국천왕★ 필수
    을파소 등용·진대법
    배경가난한 농민 구휼 필요이어짐을파소 등용·진대법
  2. 미천왕

  3. 고국원왕
    백제 근초고왕의 평양성 공격으로 전사(371)
    흐름백제 근초고왕 공격에 전사 → 소수림왕이 불교·태학·율령으로 체제 정비
  4. 소수림왕★ 필수
    불교 공인(372)·태학 설립·율령 반포
    배경고국원왕 전사 후 국가 체제 정비이어짐불교·태학·율령으로 중앙집권 강화
  5. 광개토 대왕★ 필수
    영락 연호·신라 구원·영토 확대
    배경고구려의 대외 팽창이어짐신라 구원·영토 확장 → 장수왕 남진
  6. 장수왕★ 필수
    평양 천도(427) / 백제 한성 함락(475)·개로왕 전사 / 남진 정책
    배경광개토대왕 확장의 계승이어짐평양 천도·한성 함락 → 백제 웅진 천도
  7. 고구려 고분 벽화
    무용총 수렵도·무용도 / 각저총 씨름도 / 안악3호분 행렬도
  8. 고구려 금석문
    광개토대왕릉비(장수왕 건립) / 충주 고구려비(5세기 남진 정책 자료)

백제

  1. 백제 근초고왕★ 필수
    고국원왕 전사(371) / 마한 지역 확대
    배경백제의 한강 중심 성장이어짐고국원왕 전사(371) → 한성 백제 전성기
  2. 개로왕
    장수왕 공격으로 전사(475)

  3. 무령왕★ 필수
    22담로 왕족 파견 / 무령왕릉 지석
    배경웅진 천도 뒤 왕권 회복이어짐22담로 왕족 파견 → 지방 통제 강화
  4. 성왕★ 필수
    사비 천도(538)·국호 남부여 / 관산성 전투 전사(554)
    배경웅진의 방어·통치 한계이어짐사비 천도(538) → 관산성 전사(554)
  5. 백제 고분★ 필수
    공주 무령왕릉=벽돌무덤·지석·석수 / 서울 석촌동 고분=돌무지무덤
  6. 백제 불상
    서산 용현리 마애여래삼존상=백제의 미소
  7. 백제 공예
    백제 금동대향로=부여 능산리 유적·산 모양 뚜껑
헷갈림 방지
